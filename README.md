# Terminal Odds Ticker

A Python 3.12+ terminal dashboard for exploring football odds and simulated value edges.

## Getting started

Install the project and its dependencies with `python -m pip install -e .`, then run `odds-ticker`.

Press `r` to refresh the market snapshot or `q` to quit. The mock feed updates automatically every three seconds.

## Development

Run the test suite with `python -m unittest discover tests`.
